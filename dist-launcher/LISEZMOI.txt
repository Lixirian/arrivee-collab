Arrivee Collaborateur - Lanceur
===============================

UN SEUL FICHIER A DISTRIBUER : "Arrivee Collab.cmd"
  A poser n'importe ou (bureau, dossier OneDrive, partage...), seul.
  Aucun autre fichier n'est necessaire a cote (ni .vbs, ni bootstrap.ps1).

UTILISATION (cote utilisateur)
  Double-cliquer "Arrivee Collab.cmd" (ou un raccourci vers lui). Le lanceur :
    1. lit latest.json sur GitHub (release, puis depot) ;
    2. si la copie locale (%LOCALAPPDATA%\Arrivee-Collab\app) n'existe pas,
       telecharge la derniere version, controle son empreinte SHA-256 et la
       signature de l'editeur, puis l'installe ;
    3. demarre l'application (sans fenetre console).
  Les mises a jour suivantes se font via la pastille "MAJ" de l'application.
  Journal du lanceur : %LOCALAPPDATA%\Arrivee-Collab\bootstrap.log

REPLI HORS GITHUB (optionnel)
  Si GitHub est inaccessible, le lanceur lit latest.json et
  Arrivee-Collab_version<X>.zip poses dans le MEME dossier que le .cmd.

PUBLIER UNE NOUVELLE VERSION (cote mainteneur)
  build-zip.ps1 regenere "Arrivee Collab.cmd" (en-tete + dist-launcher\bootstrap.ps1),
  le zip signe et latest.json, puis publie sur GitHub. Le .cmd ne se met pas a
  jour tout seul : le redistribuer seulement si le bundle est marque "COMPLET".
